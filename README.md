# Automation Challenge — Selenium Java Framework

Automation framework built using Java, Selenium WebDriver, 
and TestNG with Page Object Model design pattern.

## Tech Stack
- Java
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model

## What's Tested
- Login and authentication flows
- Integration pages (Acumatica, QuickBooks)
- End to end UI workflows

## How to Run
mvn test
